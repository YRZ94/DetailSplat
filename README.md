[Project page](https://yrz94.github.io/DetailSplat/)

Paper and model code will be released after acceptance. Authors and affiliations are currently withheld on the project page.

## Website template

This website follows the FreeFix project page (https://xdimlab.github.io/freefix/) and its Nerfies/Bulma template (https://github.com/nerfies/nerfies.github.io). It uses the original FreeFix Bulma and template styles, with DetailSplat text images and manuscript figures. See TEMPLATE_LICENSE.md and third-party license files.

The repository contains the static website only. It does not contain the model implementation, weights, datasets, or manuscript PDF.
